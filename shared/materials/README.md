# 公共材料库：封装与仿真共同维护

同一种具体材料、相同工艺状态与适用条件，维护同一份有来源的参数。封装和仿真不各建一份参数库。

## 当前资料

- [材料索引](catalog.csv)：材料 ID、记录位置、版本、状态与来源。
- [填写材料模板](../templates/material-entry.md)

## 两人如何协作

1. 封装协作者补充牌号、成分、工艺状态、供应商数据表及测试条件。
2. 仿真负责人核对单位、方向、温度依赖、本构适用性及模型输入。
3. 双方修改同一材料记录；引用时固定材料 ID 和 revision，更新保留变更依据。
4. 不同牌号、填料比例、固化状态、方向或试验条件不强行合并为相同数值；冲突数据保留来源与范围。
5. 仿真中的等效材料、拟合值或敏感性假设单独标记，并引用组成材料、推导/标定方法与验证范围，不能覆盖原材料属性。

## 文件规则

材料条目采用 `document_type: material`、`domain: shared`。每个参数记录单位、温度、方向、来源和状态。
案例原始输入可以作为带版本的历史快照保留；不能把未审核的工程采用值自动升级成认可材料值。

规范、目录说明不进入正式 RAG 索引；材料正文按审核状态入库。新案例优先引用已有记录，不重复抄写数值。
