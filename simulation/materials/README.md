# 材料本构与软件输入

物理材料数据统一引用 [公共材料库](../../shared/materials/README.md)，本目录不另维护一套材料数值。

这里整理仿真特有的方法知识：

- Workbench 2024 R2 Engineering Data 字段与材料属性的映射。
- 单位转换、瞬时/割线 CTE、各向异性方向和温度插值的处理。
- 弹塑性、蠕变、Anand、黏弹性等本构模型的选用与参数标定。
- 热等效/力学等效材料的推导、模型适用范围和验证方法。

案例用 `material_id + revision` 指向公共记录；软件采用的拟合/换算值要给出来源和变换规则。
如果仅为计算假设，应明确标注，不能将其混入同一材料的实测参数。
