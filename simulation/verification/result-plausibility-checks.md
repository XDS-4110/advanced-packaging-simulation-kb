# 结果可信性检查：网格合格之后还要查什么

> **网格合格 ≠ 结果正确。** 本文给网格验收之后的六项检查。

## 回答的问题与结论

**问**：结果出来了，凭什么信？

**结论**：可信性不能靠"看起来合理"判断，要靠六项可执行的检查。任一项不通过，结果只能作为排查线索，不能作为结论。

## 六项检查

### 1. 量级检查

用一阶估算对照关键量（如翘曲用 `Δα·ΔT·L²/h`，应力用 `E·Δα·ΔT`）。
**通过判据**：同一数量级，或偏差有明确解释（如约束、塑性、接触）。

### 2. 平衡检查

- 力：支反力合力与外载荷平衡；
- 热：进入与流出的热流平衡（瞬态看储能变化）。
**通过判据**：相对误差在报告声明的容差内——**容差必须写明，不能只说"基本平衡"**。

### 3. 对称性检查

对对称模型，结果应保持同样的对称性。
**通过判据**：非对称分量相对主分量为小量；若明显不对称，先查网格与接触，不要归因于"材料不均"。

### 4. 网格无关性

同一模型两套网格（粗/细），比较关键量。
**通过判据**：关键量变化率小于预先声明的阈值。**阈值要在看结果之前定**，否则会变成"看着差不多就算过"。

### 5. 外部对照

与解析解、文献、试验或上一版模型对比。
**通过判据**：差异可解释，且解释本身可核查（不是"因为材料不同"这种无法验证的说法）。

### 6. 收敛与日志复核

- 是否真正收敛（残差曲线、迭代次数）；
- 是否有被忽略的警告（接触状态改变、单元畸变、负体积）；
- 结果是否过期（改了设置但没重算）。
**通过判据**：日志中的每条警告都被分类为"已解释"或"待查"。

## 判据

六项全部通过，且容差、阈值在报告中原样给出，结果才可作为结论。**只有部分通过时，必须逐项列出未通过项。**

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 用"网格质量指标合格"代替结果可信 | 网格好但边界、材料、参考温度都可能错 |
| 容差事后调整到"刚好通过" | 检查退化为形式 |
| 只看最终时刻的收敛 | 中间步发散也可能得到收敛末态 |
| 把警告当成噪音 | 接触状态翻转常以警告形式出现 |
