# 项目统一网格要求与人工确认流程

本文是用户确认的项目网格规范，适用于后续所有模型，包括BGA、2.5D及其他封装模型，不局限于当前案例。状态reviewed表示要求及歧义已由用户确认，不表示已通过计算/实验验证，也不是对所有有限元问题的普适准确性保证。

## 网格验收要求

| 项目 | 统一要求 | 检查口径 |
| --- | --- | --- |
| 层数 | 每个实体至少3层单元 | 沿厚度或最小尺寸方向；焊球、圆柱按高度方向检查。不是3排节点 |
| 圆周 | 完整一圈至少16段 | 尽量均匀，不要求严格等分；允许超过16段 |
| 六面体形状 | 网格形状均匀、规整 | 避免原文图4区域1所示的不规则局部形状 |
| 四面体形状 | 表面三角形尽量接近等边三角形 | 避免细长、尖锐形状；以用户澄清替换原文“等腰三角形” |
| 平均质量 | 每个实体的平均Element Quality ≥ 0.75 | 每个实体分别统计，不能用整个模型平均值替代；等于0.75合格 |
| 最小质量 | Element Quality ≥ 0.05 | 等于0.05合格；低于0.05仅可走下述人工例外流程 |
| 数量 | 整个模型单元总数 ≤ 3,000,000 | 包含全部实体的单元，不是节点数；等于300万不超限 |

## 重要区域与低质量例外

1. LLM先分析仿真目标，提出重要区域和判断依据。
2. 人工确认重要区域；确认前不能由LLM擅自将某区域列为非重要区域并忽略低质量单元。
3. 如存在Element Quality < 0.05的单元，记录其所属实体、位置、数量和质量，并对照已确认的重要区域。
4. 低质量单元若全部处于已确认的非重要区域，可提出例外申请，但必须由人工单独批准；重要区域的确认不等于批准本次低质量例外。
5. 未取得例外批准，不能自动宣称该网格合格或继续自动流程。该例外仅针对最小质量，不自动豁免每个实体平均质量≥0.75等其他要求。

## 网格划分顺序

1. 先采用系统自动划分。
2. 检查全部适用要求；已全部满足时直接采用，不为添加方法而添加方法。
3. 不合格时，先调整尺寸或局部控制，并重新检查。
4. 仍不合格时按形状分支：规则六面体或由规则六面体组成的结构，优先尝试四面体；其他形状（包括柱体、薄结构、鼓形结构等）优先Sweep，再尝试MultiZone。
5. 每次修改后重新检查层数、圆周分段、形状、逐实体质量和全模型单元数；未解决的问题如实报告，不自行放宽要求。

原文“如果（5）的网格质量达到标准”按澄清后的“自动划分满足全部网格要求”表达。原文对自动网格优劣的经验性描述不另写为软件性能事实，仅保留上述项目优先顺序。

## 单元数超限处理

全模型单元数超过3,000,000时，暂停自动流程并交由人工决定。LLM可以报告超限原因和可选调整方案，但不得自行豁免上限、降低其他网格要求或执行未获决定的简化/等效。

## 自动化输出与适用边界

每次评估应输出：各实体层数与方向、圆周分段检查、各实体平均/最小Element Quality、低质量单元位置、全模型单元总数、重要区域确认记录和单独例外批准记录。未能检查的项目写明“待核实”，不能默认为通过。
