## 使用顺序

几何/材料 → 选面/接触 → 网格 → 瞬态热 → 温度传递/结构设置 → 按用户任务决定是否求解和验收。任务若仅要求瞬态热前处理，在该阶段保存并交付，不要求立刻补结构设置或求解结果。

热、结构参数只引用各案例和共享材料记录；通用阈值仅引用统一网格规范，避免重复维护。上游示例为静力结构或其他几何时，相关限制随正文保留。
