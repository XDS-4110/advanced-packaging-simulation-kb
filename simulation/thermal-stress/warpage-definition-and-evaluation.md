# 翘曲的定义、取数与评价

> 只给定义方法与判据，不含任何工程的翘曲数值。

## 回答的问题与结论

**问**：翘曲怎么定义、怎么取数、怎么判断合理？

**结论**：**"翘曲"不是一个软件输出，而是一套约定**。同一份位移结果，换一种参考平面或方向，可以得到完全不同的数值。所以必须先定义、再取数、最后才谈大小。

软件里的 Total Deformation 是**位移幅值**，含刚体运动，**不能直接称为翘曲**。

## 定义三要素

| 要素 | 要写清什么 |
| --- | --- |
| 参考平面 | 最小二乘拟合面 / 三点拟合面 / 原始未变形面 |
| 方向 | 法向（通常 Z）还是面内；单面还是双面 |
| 刚体运动 | 是否去除整体平移与转动；用什么方法去除 |

三者缺一，数值就不可复现。

## 常用定义

- **相对最小二乘平面的法向偏差**：对目标面拟合一个平面，取各点法向距离的最大值或峰谷值（PV）。对刚体运动不敏感，适合比较不同方案。
- **三点拟合平面**：用三个指定点定义平面，其余点相对它取偏差。适合与测量基准对齐（如三点支撑）。
- **原始未变形面**：直接取位移法向分量。含刚体运动，仅在约束方式明确时可用。

**报告必须写明用的是哪一种**，否则两个"翘曲 0.05 mm"可能根本不可比。

## 取样时刻

| 时刻 | 适用 |
| --- | --- |
| 峰值时刻 | 关注最坏情况 |
| 末态 | 关注稳定形态 |
| 循环稳定后（如第 2–3 循环） | 温度循环问题；首循环含初始瞬态 |

只报一个时刻而不说明理由，等于没定义。

## 量级粗估（用于合理性检查）

自由度允许时，用一阶估算对照：

- 面内热膨胀差：`Δε ≈ Δα · ΔT`
- 由该应变差引起的弯曲挠度与 `Δε · L² / h` 同量级（L 为特征长度，h 为厚度）

这一步只用数量级，不追求精度；目的是发现"差了 10 倍"这类错误。若仿真值与粗估差一个数量级以上，先查单位、参考温度与约束，而不是先怀疑材料。

## 判据

- 参考平面、方向、刚体运动处理三者均已写明；
- 取样时刻与理由已写明；
- 与网格无关性检查一起报告（换一套网格，翘曲变化在可接受范围）；
- 量级与一阶估算一致，或偏差已有解释。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 直接把 Total Deformation 当翘曲 | 含刚体位移，数值偏大且随约束变化 |
| 不写参考平面 | 换人重做得到不同数，无法比对 |
| 用自由态结果与安装态结果对比 | 两者含义不同 |
| 只报峰值不报时刻 | 无法复现 |
