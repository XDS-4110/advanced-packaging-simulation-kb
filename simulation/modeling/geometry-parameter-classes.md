# 几何参数的三类分级与失效传播

> 判据与分类，不含任何具体工程数值。

## 回答的问题与结论

**问**：改一个几何参数，会影响什么？

**结论**：几何参数不是同质的。按"改完会不会改变实体数量"分成三类，三类的下游代价差一个数量级以上。**在决定哪些参数能交给 LLM 自动扫描之前，必须先分级。**

## 三类参数

| 类别 | 定义 | 典型例子 | 实体数量 |
| --- | --- | --- | --- |
| **A 尺寸** | 只改形状或位置，不改变参与分析的实体数量 | 直径、厚度、圆角 | 不变 |
| **B 阵列** | 改变重复实例的数量、节距或排布 | 阵列数量、节距、镜像 | **改变** |
| **C 拓扑** | 增删零件、替换连接形式 | 插入中介层、增加一层 | **改变且结构变** |

**判别方法**：改完之后，导出的实体清单长度是否变化。变了就是 B 或 C，不变才是 A。

## 失效传播

| 下游对象 | A 尺寸 | B 阵列 | C 拓扑 |
| --- | --- | --- | --- |
| 实体几何 | 变 | 变 | 变 |
| 实体名称与稳定 ID 映射 | 通常保持 | **失效** | **失效** |
| 命名选择（面集合） | 面 ID 可能变，需复核 | **失效** | **失效** |
| 接触对 | 通常保持，需复核 | **失效** | **失效** |
| 网格 | 需重划 | 需重划 | 需重划 |
| 材料赋值 | 保持 | 保持（按实体名） | **失效** |
| 温度与结构载荷作用域 | 需复核 | **失效** | **失效** |
| 已有求解结果 | 失效 | 失效 | 失效 |

"失效"与"需复核"不同：前者必须重建，后者可以检查后沿用。

## 对自动化的含义

1. **A 类适合自动扫描**：一个参数改 10 次，每次只需重划网格、重跑求解，下游映射不变——这是 DOE 的天然设计变量。
2. **B 类不适合高频扫描**：每次都要重建实体映射、命名选择、接触，单次成本高出一个量级。适合少量方案对比，不适合拉丁超立方式大批量采样。
3. **C 类需要人工确认**：结构变了，物理假设也可能变。

## 判据

- 每个参数在登记时必须标注类别（A/B/C）；
- 改 B/C 类参数后，必须重建实体映射并逐项复核作用域，不得沿用旧 ID；
- 改 A 类参数后，至少复核一次命名选择与接触，不能默认"名字没变就等于面没变"；
- 参数类别一旦确定，写入参数表，并作为契约中 invalidates 字段的依据。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 把阵列数量当普通尺寸参数扫描 | 每轮都要重建全部映射，成本失控 |
| 认为"名字没变"就等于作用域没变 | 面 ID 可能已变，载荷施到了错误的面上 |
| A 类参数改完直接沿用旧网格 | 几何变了，网格与几何不再贴合 |
| 未分级就把参数交给优化算法 | 优化器会优先选影响大的参数，结果全部不可比 |
