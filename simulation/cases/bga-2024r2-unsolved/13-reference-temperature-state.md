# BGA 案例：参考温度相关证据与冲突

> 本页是实例记录，不是判据。通用判据见 [无应力参考温度](../../thermal-stress/stress-free-reference-temperature.md)。

## 结论

当前工程**没有已确定的参考温度**。界面显示"按环境"，工程内同时存在 22 ℃ 与 25 ℃ 两个数值，二者都不是参考温度。

## 证据

| 证据 | 数值 | 性质 | 位置 |
| --- | --- | --- | --- |
| `initial_conditions.InitialTemperature` | 22 ℃ | 初始条件 | `data/thermal-settings.json` |
| 温度载荷表首点（t=0） | 25 ℃ | 载荷表起点 | `data/temperature-history.csv` |
| 界面初温 | 25 ℃ | 界面可见值 | `10-thermal-ui-scope.md`（图1） |
| 实体参考温度 | "按环境" | 未手动指定 | `11-material-assignment-ui.md` |
| 缺项登记 | 高优先级 | 未取得 | `06-missing-information.md` |

`11-material-assignment-ui.md` 原文：**"不能用热初始 25 ℃ 或材料场变量默认 22 ℃ 替代它。"**

### 2026-11-03 界面复核

| 对象 | 观察 | 含义 |
| --- | --- | --- |
| 瞬态热 → 初始温度 | 均匀温度，**22.0 ℃** | 与库内记录的"初温 25 ℃"不一致，需裁定 |
| 瞬态热 → 分析设置 | 步进控制（21 步、当前第 2 步、步结束 1830 s、初始 18 s、最小 1.8 s、最大 180 s、时间积分 打开）、求解器控制、辐射控制、非线性控制 | **未见参考温度项**；右键"插入"菜单亦无 |
| 实体 `XINPIAN`（芯片） | 参考温度 = **按环境** | 继承，无数值 |
| 实体 `TUDIAN[2]`（凸点） | 参考温度 = **按几何体**，参考温度值 = **22.0 ℃** | 出现了实体级数值 |
| 初始温度改为 25 ℃ 后再次切换 | 参考温度值**仍为 22.0 ℃** | 不随初始温度变化 |

**新发现一**：不同实体的参考温度设置方式不一致（芯片按环境、凸点按几何体）。

**新发现二（用户确认）**：凸点上的 22.0 ℃ 是**切换到「按几何体」后软件自动填入**的，不是有人设定过的值。因此它**不能作为参考温度已确定的证据**，也不说明该实体曾被人手工配置。

**实验（2026-11-03，用户执行）**：把瞬态热的初始温度由 22 ℃ 改为 **25 ℃**，再对实体切换「按几何体」，自动填充值**仍为 22.0 ℃，未跟随变化**。

**结论**：自动填充值**不是**从初始温度继承的。22 ℃ 更可能来自软件内置的室温/环境默认值（与 `11-material-assignment-ui.md` 提到的"材料场变量默认 22 ℃"一致，但两者是否为同一常量尚未核实）。

**含义**：这实际上**消除了**"改工况导致零点漂移"的风险——按环境取值不随初始温度变化，因此项目约定是稳定的。代价是：22 ℃ 是一个隐式常量，不在界面上显式出现，若它可被更改，改的人未必会记录。

**工程含义（待工程决策）**：以室温为热应变零点，等价于断言器件在装配后无残余应力。对温度循环与累积损伤问题，这与按工艺温度取零点得到的结果不可直接比较。详见通用条目"两种常见约定"。

## 2026-11-03 材料侧证据（Engineering Data）

材料 `SI` 的属性表显示：

| 属性 | 值 | 单位 |
| --- | --- | --- |
| 材料场变量（表格） | 变量名称 **温度**，默认数据 **22**，程序控制 / 程序控制 | ℃ |
| 密度 | 2330 | kg m⁻³ |
| 各向同性瞬时热膨胀系数 | 2.5E-06 | K⁻¹ |
| 杨氏模量 / 泊松比 | 112.4 / 0.28 | GPa / — |
| 导热率 / 比热 | 154 / 0.713 | W m⁻¹K⁻¹ / J g⁻¹K⁻¹ |

**关键**：材料场变量「温度」的**默认数据是 22 ℃**。这解释了为什么实体切「按几何体」后自动填充 22——它取自材料场变量的默认温度，而不是分析初始温度，与实验观察一致。

属性表中未见到独立的「参考温度」字段（热膨胀用的是瞬时系数，未见割线 CTE 的参考温度行）。

## 本案例遵循的约定

按 [项目约定](../../reference-temperature-policy.md)，本模型参考温度取环境温度（当前观测 22.0 ℃），实体保持「按环境」，不逐体手填。

由此本案例的结果**不含装配残余应力**，翘曲与应力的绝对值以 22 ℃ 为零点。若将来与其他零点下的结果对比，必须先换算或重新求解。
