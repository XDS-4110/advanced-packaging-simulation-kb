# 项目温度循环标准依据 GJB 548C—2021 方法1010.1

用户明确本项目温度循环采用GJB 548C—2021《微电子器件试验方法和程序》的方法1010.1。将其登记为项目温循方法依据，BGA案例及后续沿用该方法的温循模型均引用本条目。

标准版本与方法编号由用户指定；[中国科学院上海光学精密机械研究所标准目录页](https://siom.cas.cn/jgsz/shgjskkxzx/shgjskkxzx_jctj/shgjskkxzx_jctj_jcbz/202504/t20250415_7599205.html)可核实该版本标准名称，但该页未提供可读的1010.1完整条款。本次未取得方法正文与条件表，不能据此宣称当前模型已逐条符合标准。

## 项目现有载荷记录

以下来自当前BGA工程界面及用户资料，不是本次从标准中提取的规定值：

| 参数 | 当前案例记录 |
| --- | --- |
| 温度范围 | −55～150 ℃ |
| 初始温度 | 均匀25 ℃ |
| 高、低温保持时间 | 各1800 s（30 min） |
| 高低温平台之间转换 | 每次60 s |
| 初始升温与最终恢复 | 各30 s，从25 ℃升至150 ℃，最终由−55 ℃回25 ℃ |
| 循环描述 | 5个高温平台和5个低温平台 |
| 总历程 | 18600 s，共22个载荷点 |
| 温度边界 | 直接施加于命名选择“外表面”；当前集合335面 |

[完整载荷表及界面证据](../cases/bga-2024r2-unsolved/10-thermal-ui-scope.md)保留实际输入。5循环、保温/转换时长、初末30 s及直接施加表面温度的模型处理，不自动成为所有后续模型统一采用的标准强制参数。

## 待核对的标准信息

- 方法1010.1正文、温度条件表与本项目所选试验条件代号。
- 温度上下限及容差、保持/转换时间的具体定义与要求。
- 温度测量对象/位置、循环次数要求及与具体器件规范的关系。
- 当前表面指定温度模型与标准试验实施条件的对应假设。

以上尚未从标准原文核实，不猜测条件代号，不将当前−55～150 ℃自动归入某个字母等级，也不将5循环直接描述为标准规定。

## 使用规则

回答本项目“采用哪个温循标准”时，返回用户指定的GJB 548C—2021方法1010.1。回答“是否符合标准”“具体条件等级/参数要求”时，明确原文和逐项符合性尚待核对，不能仅由该引用给出通过结论。
