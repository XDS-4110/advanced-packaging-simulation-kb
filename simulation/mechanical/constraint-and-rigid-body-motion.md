# 约束与刚体运动：怎么约束、怎么验证

> 只给判据与方法，不给任何工程的约束方案。

## 回答的问题与结论

**问**：这个模型该怎么约束？会不会过约束？

**结论**：约束的作用是**消除刚体运动**，不是"把模型按住"。约束不足会得到整体漂移的结果，约束过多会人为引入应力并改变翘曲形态——**两者都不会报错**，只能靠检查发现。

## 先分清三种状态

| 状态 | 含义 | 用途 |
| --- | --- | --- |
| 自由态（free） | 不加约束，用惯性释放或平衡力系 | 求**自由翘曲**形态 |
| 安装态（constrained） | 按实际安装方式约束 | 求**装配后的实际响应** |
| 对称态 | 用对称面代替一半模型 | 缩减规模；要求几何、载荷、材料都对称 |

**自由态与安装态的翘曲不可直接比较**——前者是形态，后者含约束反作用。报告中必须说明用的是哪一种。

## 约束方案的基本做法

- **3-2-1 法**：一个面限制法向位移，一条线限制两个方向，一个点限制三个方向，恰好消除六个刚体自由度。
- **对称面**：对称面上施加对称约束，前提是对称性真实成立。
- **底面全约束**：最常见，也最容易过约束——它把整个底面固定，等于禁止底面任何热膨胀，会在底面附近产生非物理的应力与翘曲。

选择哪一种取决于**实际安装方式**，不是取决于哪种"容易收敛"。

## 如何发现约束不足

- 位移场出现整体平移或转动（数值很大且方向一致）；
- 反力合力接近零而外载不为零；
- 模态分析前六阶频率接近零（诊断用，不用于求解）。

## 如何发现过约束

四项检查，任一异常都要回查：

1. **反力平衡**：支反力合力与外载荷应平衡；不平衡说明约束参与了承载。
2. **约束处应力**：约束面附近出现明显高于内部的应力集中，通常是人为固定造成的。
3. **应变能占比**：约束区域吸收的应变能占比过高，说明模型在"顶"约束。
4. **扰动测试**：松开一处非关键约束，若结果几乎不变，说明该约束本可不加；若结果剧变，说明它承担了非物理的作用。

## 判据

同时满足才算约束方案可用：

- 约束位置与实际安装方式一致，并记录依据；
- 无刚体位移（位移场无整体漂移）；
- 反力与外载平衡；
- 通过扰动测试，无"非必要但影响巨大"的约束；
- 报告写明是自由态还是安装态。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 底面全约束后讨论"自由翘曲" | 结果里混入了约束反作用 |
| 用"能算通"作为约束合理的依据 | 过约束同样能收敛 |
| 对称模型却在对称面施加固定约束 | 等于把对称面焊死，形态完全改变 |
| 约束点选在会随热变形的面上 | 人为限制热膨胀，应力虚高 |
