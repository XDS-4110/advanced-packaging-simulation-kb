# 焊点应力与应变的取数方法

> 只讲"取哪个值"，不讲材料参数与寿命公式。

## 回答的问题与结论

**问**：焊点应力取哪个值？

**结论**：**不能直接报最大节点应力。** 焊点与界面处存在几何尖角，应力随网格加密持续增大（应力奇异），最大值没有收敛性。可用的取数是"路径平均"或"体积平均"，并且必须写明位置、方式与半径。

## 为什么最大应力不可用

- 尖角处理论应力无穷大，数值随单元尺寸变化；
- 换一套网格，最大值可能差几倍，而其他量基本不变；
- 因此最大值反映的是**网格**，不是**结构**。

判别方法：把网格加密一档，看该处最大值是否显著上升。上升即奇异。

## 临界位置怎么选

| 判据 | 说明 |
| --- | --- |
| 距中性点最远 | 热失配位移最大 |
| 最外圈焊点 | 约束最小、变形最大 |
| 界面处（焊料/铜或焊料/基板） | 失效通常发生在界面 |

选一个位置并在报告中说明理由，不要"取全场最大"。

## 取数方式

| 方式 | 做法 | 适用 |
| --- | --- | --- |
| 路径平均 | 沿界面定义一条路径，取路径上平均或指定区段平均 | 界面失效 |
| 体积平均 | 取焊点内一个球或圆柱区域的体积平均 | 整体响应 |
| 危险点排除 | 排除界面 1–2 层单元后取次大值 | 快速筛查，需说明排除规则 |

无论哪种，**半径或路径定义必须写明**——半径不同，数值可差数倍。

## 应力还是应变

- **弹性分析**：报等效应力，但要知道它不代表失效；
- **含塑性/蠕变**：报等效塑性应变或非弹性应变能密度，它们对网格的敏感性低于应力；
- 两者不可混用，报告中须说明用的是哪一种。

## 循环稳定性

温度循环问题中，首个循环含初始瞬态。应在报告中说明取第几循环、以及如何判定已稳定（相邻循环同一量的变化率小于声明阈值）。

## 判据

- 临界位置与选择理由已写明；
- 取数方式（路径/体积）、半径或路径定义已写明；
- 网格敏感性已检查并给出结论；
- 明确是应力还是非弹性应变；
- 循环数与稳定性判据已写明。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 报全场最大节点应力 | 数值由网格决定，不可复现 |
| 取数半径不写 | 他人无法复算 |
| 用弹性应力推断寿命 | 焊料行为是率相关的，弹性结果不含累积损伤 |
| 只取第一循环 | 含初始瞬态，偏保守或偏乐观且不可比 |
