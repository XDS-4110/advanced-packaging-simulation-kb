# 非线性与求解设置：开关、收敛与不收敛排查

> 只讲判断依据与排查顺序，不给具体数值设置。

## 回答的问题与结论

**问**：大变形开不开？子步怎么给？不收敛怎么办？

**结论**：三个开关（大变形、时间积分、材料非线性）各自对应一类物理效应，**不是"开了更准"**；子步与收敛设置应由物理时间尺度决定，而不是由"能不能算完"倒推。

## 三个开关

| 开关 | 什么时候需要 | 误开的代价 |
| --- | --- | --- |
| 大变形 | 位移与结构尺寸相比不可忽略（明显弯曲、大挠度） | 增加计算量；对薄结构可能引入收敛困难 |
| 时间积分 | 瞬态、率相关材料、惯性不可忽略 | 稳态问题开它只增加成本 |
| 材料非线性（塑性/蠕变/粘塑性） | 应力超过弹性范围，或需要累积非弹性应变 | 无标定数据时开启只会产生不可信结果 |

**共同原则**：每个开关都要能回答"为什么开"，写进案例记录。

## 子步与时间步

- 时间步应能分辨载荷变化的最快特征（如升降温速率、保温段起点）；
- 自动时间步有上下界，边界应能覆盖上述特征，而不是让软件自由发挥；
- 判断依据：把最大时间步减半，关键量变化在声明阈值内。

## 收敛准则

- 力/位移残差、能量准则各有适用场合，报告中写明用的是哪一种；
- 容差不能事后放宽以"通过"；若要放宽，必须先说明物理理由并记录；
- 收敛不等于正确：收敛只说明方程解出来了。

## 不收敛的排查顺序

按此顺序，逐层排除，不要跳步：

1. **接触**——状态翻转、初始间隙/穿透、刚体位移；
2. **材料**——参数超出适用范围、单位错误、本构与载荷不匹配；
3. **网格**——畸变单元、负体积、接触面网格不匹配；
4. **载荷步**——突加荷载、时间步跨越特征、边界条件冲突；
5. **求解器**——线性求解器类型、大变形开关、阻尼设置。

把每一步的尝试与结果记录下来，否则同一问题会重复排查。

## 判据

- 每个开关的开启理由已记录；
- 时间步敏感性已检查并给出结论；
- 收敛准则与容差已写明，未事后调整；
- 不收敛时保留了排查记录，而非只保留最终能跑通的设置。

## 常见错误

| 错误 | 后果 |
| --- | --- |
| 用"能收敛"反推设置正确 | 收敛性与物理正确性无关 |
| 出现警告后直接放宽容差 | 掩盖了接触或材料问题 |
| 大变形默认开启 | 部分问题因此不收敛，且原因难查 |
| 时间步只由"算得快"决定 | 错过载荷特征，结果系统性偏差 |
