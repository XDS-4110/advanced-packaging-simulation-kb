# COMSOL 知识库迁移记录（2026-11-16）

## 删除范围

- 旧软件操作教程、排错目录和专用 API 来源。
- 旧未求解 BGA 工程、对象编号、温度表、材料修订、截图转录及报告—工程对照；这些证据无法证明当前 COMSOL 项目状态。
- 旧写入契约、静态回执、CAD COM 执行脚本和环境接入说明；没有迁移成新的求解器执行接口。
- 旧项目专用网格控制及隐式参考温度规则，避免历史数值成为现行默认输入。

## 保留范围

电子封装基础、BGA / 2.5D / TSV 结构与工艺、材料机理、可靠性、独立论文和厂商来源；来源的版本、许可及未取得全文等限制继续保留。来源表仅逐行移除明确废弃的软件/旧工程来源，不删除其他贡献者资料。

## 待审核

COMSOL 官方文档归纳、修改后的方法条目均保持 draft。历史 reviewed 来源不自动授予改写条目 reviewed 状态。旧项目用户决策来源仍可追溯，但不作为当前软件的通用参数。实体与材料表留空，不伪造新工程。

检索器只读；本次未把 MCP 接入客户端、未运行 COMSOL 模型。资料完整性、来源引用、索引与草稿门禁由静态检查核验；软件运行和物理验证需要独立证据。

## 重建与检查

全部官方文档入库后运行 `python tooling/rebuild_metadata.py`，再运行 `python tooling/ci_check.py` 与 `python tooling/kb_retrieve.py eval`。重建同步 corpus-baseline.json 与 packaging/data/knowledge-index.json；不得通过修改审核状态让测试通过。
