# 器件级、板级与局部BGA模型范围

## 先由目标确定模型边界

| 分析目标 | 至少需要的对象 | 范围不足时不能得出的结论 |
| --- | --- | --- |
| 封装自身翘曲 | 芯片、基板、封装材料及内部连接的有效刚度 | 没有PCB时不能直接给出板级焊点疲劳 |
| 板级焊点热疲劳 | 封装、外部焊点、PCB及实际支承 | 单个自由球不能代表板级失配载荷 |
| 焊点局部应变或裂纹 | 接头、焊盘、邻近材料与有效远场载荷 | 没有界面模型不能预测脱粘扩展 |
| 系统散热 | 发热区、PCB、外壳或散热器及环境边界 | 只建封装不能宣称复现机箱内结温 |

器件级模型不等于完全自由，板级模型也不等于 PCB 底面完全固定。应按夹具、螺钉、支架或实际连接确定边界；为消除刚体运动使用的数值约束不能替代真实安装结构。

## 全局与局部模型如何衔接

全局模型用于整体温度、翘曲和载荷传递，局部子模型用于焊点或界面细节。子模型边界需从全局结果映射位移及必要温度，不应简单把切面全部固定。检查边界位置敏感性，避免切面过近主导热点结果。

二维剖面不能自动代表整个三维球阵列。平面应力、平面应变和轴对称有不同物理假设；BGA 完整矩形阵列通常不轴对称。局部单球轴对称近似不能表示一般板级面内剪切。

## 对称与等效的限制

使用半模型或四分之一模型，需几何、材料方向、载荷、缺陷及支承同时满足对称性。偏置芯片、非对称铜层、缺球或局部热源可能破坏对称。周期单胞适合重复结构的等效研究，不直接描述自由边缘和角部焊点。

省略部件前说明其导热、质量、刚度和载荷路径是否被等效保留。把整个封装用均匀块代替后，仍需验证目标响应，而不能只比较总质量。
