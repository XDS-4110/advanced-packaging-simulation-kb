## 如何新增文件

复制 [填写模板](../../../shared/templates/reference-note.md) 到本目录，另起有意义的文件名，例如 `topic-note.md`（仅为命名示例）。

- 必填内容：作者、年份、标题、DOI/URL、版本；是否读到全文；关键页码/图表；原文结论、个人理解和项目用途。
- 自查：翻译笔记保留原文定位；不把个人推断写成原文结论，不直接上传未经许可的全文。
- 元数据：唯一 id、domain: packaging、status: draft、source_ids、原文页码或图表、更新日期。
- README 仅作导航；新增正文后在下方添加链接。
