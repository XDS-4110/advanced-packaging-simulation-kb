# BGA塑封体、金属盖与加强框

## 上部结构的三种常见形式

塑封型以模塑材料包覆内部部件；裸背型保留芯片背面外露；带盖型在芯片上方设置金属盖。它们决定封装顶部由何种实体构成，不能把“顶部平面”统一解释成硅表面。

| 部件 | 典型位置 | 结构作用 |
| --- | --- | --- |
| 塑封体 | 芯片及互连周围或上方 | 保护内部部件，参与整体刚度和变形 |
| 金属盖（lid） | 芯片上方 | 保护芯片，并可扩展热量传出的面积 |
| 热界面材料（TIM） | 芯片背面与盖之间 | 填充接触间隙，形成热连接 |
| 盖体粘接层 | 盖的支撑或边缘连接区域 | 把盖固定到基板或相应支撑结构 |
| 加强框（stiffener） | 通常位于基板上、芯片周围 | 提高结构刚度，可能兼作盖体支撑 |
| 外部散热器（heat sink） | 封装顶部之外 | 属于系统散热组件，可通过另一层TIM连接封装 |

## 不同胶层不能合并理解

芯片下的底填胶、芯片背面与盖之间的TIM、盖边缘的粘接胶处于不同位置，连接对象和用途不同。TIM不一定承担盖体全部固定作用。带盖结构也不必同时存在独立加强框。

## 读剖面的顺序

先辨认芯片有源面方向，再确认内部互连；随后辨认芯片上方是塑封料、空气还是TIM及盖体。沿盖体边缘查找其支撑和固定位置。最后确认外部散热器是否画入装配范围。

未经过框体的剖切面可能看不到加强框；局部剖面不显示某部件，不能据此断定整个封装没有该部件。
