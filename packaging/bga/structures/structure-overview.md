# BGA结构总览与识别

## BGA由什么组成

BGA（Ball Grid Array，球栅阵列）描述封装底部以阵列焊球形成外部端子的形式，不指定芯片内部采用何种互连。认识结构应分三层：芯片、芯片到封装基板的内部互连、封装到系统PCB的外部互连。

| 层级 | 主要实体 | 作用 |
| --- | --- | --- |
| 芯片 | 半导体裸片、表面焊盘及钝化层 | 实现电路功能；焊盘是电连接出口 |
| 内部互连 | 键合线，或倒装凸点及相应连接焊盘 | 把芯片电连接引到封装基板 |
| 封装载体 | 封装基板、布线、层间通孔 | 支撑芯片并重新分配连接位置 |
| 外部互连 | 基板底面焊盘、焊球 | 与PCB焊盘连接 |
| 保护与支撑 | 固晶层、塑封体、底填胶或金属盖等 | 随结构选择，承担固定、保护、传热或增强刚度的作用 |

PCB是装配对象，不是独立BGA器件自身的一部分。剖面图画出PCB，只表示展示了板级装配。

## 名称分别描述什么

- WB-BGA：内部使用引线键合，通常芯片有源面朝上。
- FC-BGA：内部使用倒装互连，芯片有源面朝向基板。
- PBGA：强调塑料封装体系，不能仅凭名称判定内部一定采用线焊。
- CBGA：强调陶瓷载体；不能把陶瓷基板当作有机树脂基板。
- 裸背、塑封、带盖：描述芯片上方的保护或散热结构，可与内部互连形式组合。

只有底面照片通常只能识别球阵列，不能判定内部是线焊还是倒装。识别内部结构需要剖面、爆炸结构或部件定义。

## 两条典型连接链

线焊：芯片焊盘 → 键合线 → 基板上表面键合焊盘 → 基板布线及通孔 → 底面焊盘 → 外部焊球 → PCB焊盘。

倒装：芯片焊盘 → 凸点连接结构 → 基板上表面焊盘 → 基板布线及通孔 → 底面焊盘 → 外部焊球 → PCB焊盘。

一个芯片连接点不一定对应唯一外部焊球：电源、地等网络可能在基板中汇接；球数也不等于信号数。
