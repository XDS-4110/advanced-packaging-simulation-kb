# BGA封装基板的层叠与连接

## 封装基板不是均匀树脂块

封装基板兼有承载与布线作用。有机基板由介质与金属导体构成，导体包括表面焊盘、走线、电源或地平面及层间连接。芯片侧细密连接通过基板重新分布到较大范围的外部端子。

## 典型层叠

一种有芯有机基板可从上至下表示为：上表面阻焊层及开口 → 顶部铜图形 → 上侧积层介质与铜布线 → 芯板 → 下侧积层介质与铜布线 → 底部铜焊盘 → 下表面阻焊层及开口。

这只是结构类型，并非所有BGA的固定层数。无芯基板不保留传统芯板；陶瓷基板采用另一种介质及导体体系。BT通常指树脂体系，ABF通常用于积层介质，两者都不是“完整基板”的唯一材料定义。

| 结构 | 位置与作用 |
| --- | --- |
| 芯板（core） | 有芯基板的中央支撑部分，可含贯通连接 |
| 积层（build-up） | 在芯板一侧或两侧形成的细布线介质/导体层 |
| 铜走线 | 在同一布线层传递电信号 |
| 电源/地平面 | 较大面积导体，承担供电或参考网络功能 |
| 通孔 | 在不同金属层之间建立电连接 |
| 阻焊层 | 覆盖部分表面导体，在需要连接处保留开口 |

## 通孔的区别

贯通孔穿过其所属板体的整个厚度；盲孔从外层通向内层；埋孔连接内层而不直接露出板体表面。积层微孔可采用堆叠或错位布置。应同时说明孔所在板体、连接层和是否填铜，不能仅凭“via”判定是实体铜柱。

封装基板通孔与PCB通孔属于不同部件。硅通孔TSV则穿过硅体，不能用来泛称有机基板通孔。
