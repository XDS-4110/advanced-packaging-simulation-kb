# BGA球阵列与装配尺寸

## 球阵列的平面几何

球阵列可为满阵列、外围阵列或带有局部缺球的阵列。阵列的行列范围表示可用位置范围，实际球数等于已占据位置的数量，不能一律用行数乘列数。

| 尺寸 | 含义 | 不能混用的量 |
| --- | --- | --- |
| 节距 p | 相邻阵列位置的中心距 | 球边缘之间的净间距 |
| 植球前球径 | 独立焊球的直径 | 回流后的焊点最大宽度 |
| 焊点高度 h | 指定上下连接面之间的焊点高度 | 球径、封装总高 |
| 焊盘直径 | 金属焊盘的平面直径 | 阻焊开口直径 |
| 封装外形尺寸 | 封装体的长度和宽度 | 球阵列中心跨度 |
| 边缘偏置 | 最外侧球中心到指定封装边缘的距离 | 最外侧球边缘到封装边缘的距离 |

## 规则阵列的坐标关系

对未旋转的正交规则阵列，设第一个位置中心为 (x₀,y₀)，X/Y方向节距为 pₓ、pᵧ，第 i 列、第 j 行的中心为：

xᵢ = x₀ + i pₓ，yⱼ = y₀ + j pᵧ。

i、j从0开始，所有长度使用同一单位。缺球位置仍保留其阵列坐标，只是不放置球体。N列完整规则位置的首末中心跨度为 (N−1)pₓ；这不是封装宽度。错列阵列需要逐行偏置，不能直接套用同一个x₀。

## 顶视图和底视图

从封装顶面看和从焊球面看是不同观察方向。球图必须结合A1标记及图纸视图解释；将底视球图直接当成顶视PCB布局，可能产生镜像错误。字母行号也不一定连续使用所有字母。

## 装配前后尺寸

植球后焊球已与封装焊盘结合，形状就不必是完整球体。与PCB回流连接后，焊点外形受焊料体积、两端润湿范围和装配间隙影响，常表现为鼓形或两端受约束的曲面。不能用一个球径同时定义焊点高度和宽度。

共面度描述端子相对于规定基准面的偏离；翘曲描述封装或基板表面的非平面变形。两者相关但不是同一尺寸指标。
