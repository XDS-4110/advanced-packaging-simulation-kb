# 倒装BGA的部件与连接关系

## 芯片与基板如何相接

FC-BGA的芯片有源面朝下，通过分布在芯片连接位置的凸点接到基板上表面。芯片背面朝上，可裸露、被塑封料覆盖或经热界面材料连接金属盖。

| 部件 | 位置及作用 |
| --- | --- |
| 芯片 | 有源面朝向基板，背面朝向封装顶部 |
| 芯片焊盘及连接金属层 | 将芯片电路连接到凸点；具体金属堆叠取决于工艺 |
| 倒装凸点 | 跨越芯片与基板之间的间隙，承担电连接和局部机械连接 |
| 底填胶（underfill） | 通常填充凸点之间的间隙，分担芯片与基板相对变形引起的载荷 |
| 基板上表面焊盘 | 接收芯片凸点并连入基板布线 |
| 封装基板 | 将芯片连接布局转换为外部球阵列布局 |
| 底部焊球 | 连接封装基板和PCB，属于另一层互连 |

## 凸点与外部焊球必须分开识别

芯片下凸点与封装底部焊球处在不同高度、连接不同对象，数量、节距、材料及形状均可能不同。倒装凸点可采用焊料凸点，也可采用铜柱与焊料端部等复合结构；铜柱不能整体等同于焊料。

凸点阵列不必铺满整个芯片底面。其连接可能分布于面阵列或局部区域，不能由芯片面积推算数量。

## 底填胶的几何形态

底填胶与凸点共同占据芯片和基板之间的空间：胶体包围凸点，而不是与凸点占据同一体积。底填胶在芯片边缘可能向外延伸形成胶脚（fillet），其爬升高度和外伸宽度不同于芯片下方的间隙厚度。

典型底填结构可分为芯片—底填胶界面、基板—底填胶界面和凸点周围界面。空洞是填充区内部缺少材料的区域；脱层是原本结合的界面发生分离，两者不是同一种几何缺陷。

## 顶部结构的变化

塑封倒装BGA、裸背倒装BGA、带盖倒装BGA的上部结构不同。塑封料与底填胶可以是分立材料；模塑底填工艺也可使模塑材料进入芯片下方。不能仅凭“FC-BGA”名称判断是否有塑封体、金属盖或独立底填层。
