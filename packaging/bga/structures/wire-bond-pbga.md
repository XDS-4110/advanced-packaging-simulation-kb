# 线焊PBGA的部件与连接关系

## 从上到下认识剖面

典型单芯片线焊PBGA中，芯片背面通过固晶层固定在基板上，有源面及芯片焊盘朝上。键合线从芯片表面跨接到芯片周围的基板键合焊盘。塑封体包覆芯片、引线及相应基板上表面区域，基板底面排列外部焊球。

| 部件 | 位置与结构作用 |
| --- | --- |
| 芯片 | 位于基板上方，背面承担固晶连接，有源面提供焊盘 |
| 固晶层（die attach） | 位于芯片背面和基板之间，固定芯片并形成传热通路；可采用胶或膜等形式 |
| 键合线（bond wire） | 两端连接芯片焊盘和基板焊盘，中段形成离开表面的弧形线环 |
| 基板键合焊盘 | 通常位于芯片外围，与基板内部布线相连 |
| 塑封体（mold cap） | 包围脆弱的芯片及引线，提供环境与机械保护 |
| 封装基板 | 承载上述部件，将内部焊盘扇出至底面球阵列 |
| 外部焊球 | 植于基板底面，板级装配后形成与PCB的焊点 |

## 引线不是水平直线

键合线需要越过芯片边缘并保留空间间隙。线径、线环高度、水平跨距、焊点位置和相邻引线间距共同决定其三维形状。线环最高点与塑封顶部之间应有包覆空间。平面投影交叉不能直接证明三维引线接触，必须结合高度判断。

## 固晶层与底填胶的区别

固晶层连接芯片背面和承载面；倒装底填胶主要位于芯片有源面与基板之间并包围凸点。两者位置和连接对象不同。普通线焊PBGA不因采用BGA外部端子就自动具有芯片下凸点和倒装底填胶。

固晶材料可能导电，也可能绝缘；不能仅由“固晶胶”名称判断芯片背面是否电连接到基板。多芯片或堆叠芯片线焊结构还可能包含额外固晶膜、垫片和不同高度的线环。
