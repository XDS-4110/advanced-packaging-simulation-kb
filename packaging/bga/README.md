## 内容目录

- [BGA 基础](fundamentals/README.md)：BGA 定义、命名与分类；塑封、陶瓷、线焊和倒装等分类维度；器件级与板级研究范围。
- [BGA 结构](structures/README.md)：线焊型与倒装型结构；芯片下凸点与底部焊球；球数、球径、节距、排列、焊盘与回流后高度；是否包含 PCB。
- [BGA 工艺](processes/README.md)：植球、器件端与 PCB 端焊盘、板级回流、检测及返修；引用共用回流和底填知识。
- [BGA 可靠性](reliability/README.md)：底部焊点疲劳、封装与 PCB 变形失配、翘曲相关装配缺陷；区分器件内部凸点和板级焊点。
- [BGA 案例](cases/README.md)：实际封装结构、尺寸、材料来源、工艺与工况、测试记录和资料缺口。
- [BGA 文献笔记](references/README.md)：BGA 器件手册、封装尺寸图、焊点可靠性论文、材料来源与实验报告。
