# 测温位置、控温目标与芯片温度的区别

## 一个“温度”必须先说明测在哪里

课程在TEC附近放置激光器和热敏电阻，并通过热敏电阻反馈讨论温度控制。传感器温度、TEC表面温度和芯片内部温度对应不同位置；有热流经过有限导热路径时，它们不必相同。因此“传感器控制到50°C”不等于“所有芯片位置都是50°C”。这里50°C仅是课程例子，不是任何激光器或BGA的推荐设定值。

下半段约59分钟展示截面温度，讲解区分截面/表面读数与监测点读数。这提示我们：比较温度结果前，应先确认是点值、区域平均值、最高温度，还是测量装置的读数；不能把这些量混用。

## 温度记录的最小完整描述

| 字段 | 要解决的问题 |
| --- | --- |
| 测量对象和坐标 | 温度属于芯片、封装表面、基板还是环境？位置在哪里？ |
| 测量/输出定义 | 热敏电阻读数、热电偶读数、红外测温或仿真点/面/体统计？ |
| 时间状态 | 稳态、启动过程还是循环中的某一时刻？ |
| 安装和界面 | 传感器怎样贴合，是否通过胶或支撑件连接？ |
| 功耗与散热工况 | 哪些部件工作，环境、气流和散热接口是什么状态？ |
| 误差与校准 | 测量精度、位置公差和校准依据能否追溯？ |

上表是本项目整理建议，不是课程提供的统一试验规范。具体传感器的校准和误差应查型号资料，未知信息不估填。

## 均匀性与最高温度不能互相替代

若研究温度均匀性，需先定义区域、时刻和度量，例如指定表面的最高温减最低温。区域平均温度较低不能证明局部热点满足要求；同样，一个控温点稳定不能证明整片芯片温度均匀。两枚芯片的结果还应使用一致的区域和统计定义。

## 封装侧应如何交接

在装配图中标出热源、传感器、被控位置及散热接口，分别列出“实际读数”“控制设定”和“需要验证的目标温度”。如需要从传感器读数估算芯片结温，应提供该结构和工况下的关联依据，不能凭距离近就视为相等。

本条适用于带传感器的封装/板级实验；不替代特定器件的结温测量方法，也不提供控制器调参步骤。阅读范围与证据见[TEC视频笔记](../references/course-video-tec.md)，状态为draft。
