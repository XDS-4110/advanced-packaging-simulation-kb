# 电子封装共用基础

通用定义、原理与结构单元集中维护，供专题引用。

## 内容目录

- [基础概念](fundamentals/README.md)：封装作用与层级；封装基板和 PCB 的区别；互连层级；热阻、热膨胀失配、应力应变、蠕变与松弛的概念。
- [通用结构单元](structures/README.md)：芯片、焊盘、凸点、焊球、基板、RDL、TSV、键合线、底填胶、塑封料与 TIM 的定义、位置及作用；不将这些单元认定为某个专题独有。
- [材料知识与公共库入口](materials/README.md)：Si、铜、焊料、基板介质、Underfill、塑封料及 TIM 的作用；牌号、成分、固化状态、温度依赖、各向异性、Tg 与物性测试条件。
- [共用工艺](processes/README.md)：芯片贴装、线焊、倒装互连、回流、底填、塑封及固化；记录工艺顺序与温度历史，区分通用流程和具体器件已确认流程。
- [可靠性基础](reliability/README.md)：热失配、疲劳、界面分层与开裂；温度循环与热冲击的区别；翘曲测量、试验条件、失效判据及实验依据。
- [共用文献笔记](references/README.md)：整理材料、结构、工艺与可靠性的原始资料，定位到章节、页码、图表及版本。

材料属性引用 [公共材料库](../../shared/materials/README.md)，不复制参数。当前为待补充目录；条目需登记来源并审核。
