# 键合线几何、工艺可制造性与电连接

## 键合线不能只记录一个长度

课程的光封装例子连接了载板焊盘、芯片焊盘及参考导体。对采用线焊的BGA或其他封装，可迁移的是结构描述方法：保存起点/终点所属焊盘、线材与线径、线弧形状和高度、方向、线间距以及周围部件间隙。不能仅用两个焊盘之间的平面距离代表实际线长。

课程17:00–21:45讨论线弧、落点与正反向打线，并提醒与工艺人员确认。CAD中能画出的低线弧或紧密排列，不等于设备和工艺能稳定制造。课程界面中的线径、线高是演示值，不能直接作为目标封装的能力边界。

## 几何、材料与电连接要分开描述

两个金属结构采用同一种材料，并不意味着它们电气相连；同一网络也可能通过多段金属和过孔连接。把所有同材质导体合并成一个实体，可能丢失独立网络和部件边界。反过来，图形上看似分开的导体也可能通过过孔或底层金属相连。

课程下段先遇到模型实体未正确分开的情况，后来又定位到过孔误连信号与地的问题。对封装资料来说，应同时保留几何剖面/布局与连接表，不能只给仿真负责人一张彩色模型截图。

## 交接内容

| 项目 | 推荐保存的信息 |
| --- | --- |
| 键合线 | 标识、起止焊盘、材料、线径、线弧参数及单位 |
| 焊盘与网络 | 焊盘位置/尺寸、信号/电源/地或其他网络标识 |
| 过孔 | 坐标、连接层、填充、孔径和实际工艺可达范围 |
| 间隙 | 线间、线与封装体/芯片/盖板的间隙及公差 |
| 制造依据 | 图纸版本、工艺能力或实测线弧，而非仅软件默认形状 |

同一结构用于热、电或力分析时，可以采用不同简化，但应保留原始结构事实。是否能省略键合线及怎样等效，应由研究目标和误差验证决定；“对某一热结果影响小”不能直接推广到高速信号或局部机械失效。

## 适用范围与来源边界

适用于采用键合线互连的封装；不把光器件的阻抗目标、过孔纵横比或优化结论迁移为BGA通用规范。电磁端口、扫频和网格设置由simulation维护。课程原始工程未复现，本文为draft；视频阅读范围见[光通信案例笔记](../references/course-video-optical.md)。
