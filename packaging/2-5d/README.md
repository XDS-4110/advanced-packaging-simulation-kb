# 2.5D 专题

本入口维护专题结构与应用差异，通用原理引用 [共用基础](../common/README.md)。

## 内容目录

- [2.5D 基础](fundamentals/README.md)：2.5D 架构定义、分类口径及与其他集成方式的区别；避免将中介层材料或某个厂商实现视为唯一形式。
- [2.5D 结构](structures/README.md)：硅、有机、玻璃中介层与局部桥接；芯片布局、间距、多级互连；TSV、RDL、微凸点在具体架构中的作用。
- [2.5D 工艺](processes/README.md)：中介层制造、薄化与搬运、多芯片贴装、键合、底填及组装顺序；记录制造热历程。
- [2.5D 可靠性](reliability/README.md)：芯片间热耦合、大尺寸中介层翘曲、多材料界面失配和微互连可靠性；记录具体架构与实验条件。
- [2.5D 案例](cases/README.md)：实际架构、层叠、芯片布局、材料、功耗分布、散热配置、工艺及试验资料；涉及 BGA 时链接对应知识。
- [2.5D 文献笔记](references/README.md)：中介层、桥接、多芯片集成的结构、工艺和可靠性原始资料。

材料属性引用 [公共材料库](../../shared/materials/README.md)，不复制参数。当前为待补充目录；条目需登记来源并审核。
