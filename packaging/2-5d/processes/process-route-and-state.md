# 2.5D工艺路线与装配状态

## 先确定中介层路线

2.5D 描述多个芯片通过中介互连集成的架构，不规定唯一制造顺序。工艺输入必须明确中介层材料、互连形式、芯片朝向和组装层级。

| 路线 | 需记录的制造对象 | 不可自动添加的部件 |
| --- | --- | --- |
| 全尺寸硅中介层 | 硅本体、TSV、正背面布线与焊盘 | 不能把整个硅层当成封装有机基板 |
| RDL 中介层 | 聚合物介质、金属再布线、垂直互连及承载结构 | 不因出现“中介层”就添加硅和 TSV |
| 局部硅桥 | 桥的嵌入位置、桥上细互连、周围介质及基板布线 | 不把局部桥扩大成覆盖所有芯片的硅片 |

硅中介层的一种逻辑流程是完成互连与背面处理、建立芯片到中介层连接、再形成中介层到封装基板连接；实际晶圆级和单颗级路线的切割、底填及转移顺序可不同。每一步必须按目标工艺实例排序，不能把逻辑层级当作厂商操作规程。

## 三个连接层级

芯片到中介层的微互连、中介层到封装基板的连接、封装基板到 PCB 的 BGA 焊点，分别使用不同部件集合与连接表。HBM 内部堆叠互连属于第四个可选细化层级，不因 HBM 装到中介层上就重新执行内部堆叠工艺。

| 阶段状态 | 必需输入 | 输出给后续阶段 |
| --- | --- | --- |
| 裸中介层 | 层厚、铜分布、初始翘曲及已有残余应力 | 初始几何和材料状态 |
| 芯片键合 | 贴装顺序、温度、压头与承载条件 | 微互连形状、残余偏移及应力 |
| 底填或塑封 | 填充范围、固化曲线、工装状态 | 固化度、收缩、松弛后的状态 |
| 上基板 | 下层连接与基板翘曲 | 新增连接、冷却后的整体变形 |
| 安装散热结构 | TIM、盖板、加强环及胶层 | 预紧与热接触状态 |

## 建模及绘图约束

COMSOL 或 ANSYS 模型中每个阶段要明确“已有、加入、移除、释放”的实体和界面。载具存在时才提供相应支承；芯片贴装之前不得存在芯片底填的承载贡献。阶段图用同一坐标系与部件编号，临时载具使用独立图例。未知温度、压力、时间和尺寸保留变量，不填写所谓通用工艺值。
