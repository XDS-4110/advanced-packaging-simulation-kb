# 微凸点、中介层连接与BGA焊球

## 用连接对象识别互连层级

| 层级 | 上端与下端 | 典型结构 |
| --- | --- | --- |
| 芯片级 | 功能芯片—中介层或桥接区域 | 微凸点、铜柱及焊料连接等 |
| 中介层级 | 中介层—封装基板 | C4焊料凸点或相应铜柱连接等 |
| 板级 | 封装基板—PCB | BGA焊球回流形成的焊点 |

此表适用于有独立中介层和封装基板的典型结构。局部桥接不一定具有覆盖整个封装的“中介层—基板”凸点层。C4是连接技术名称，不是一个通用直径值。

## 互连的材料层次

芯片焊盘、凸点下金属层（UBM）、铜柱、焊料及对侧焊盘可以构成连接堆叠。UBM用于使芯片焊盘与后续凸点金属形成合适的连接界面；实际层数与材料随工艺而变。铜柱加焊料的结构不能全部视为焊料球。

回流后焊料会在可润湿区域形成受两端约束的形状，未必保留原始球形。凸点高度应以装配后的连接面定义，不能从平面焊盘直径推出。

## 横向信号路径与向下路径

典型横向路径为：芯片A焊盘 → 芯片级连接 → 中介层细布线 → 芯片级连接 → 芯片B焊盘。

典型向下路径为：芯片焊盘 → 芯片级连接 → 中介层布线与垂直通孔 → 中介层级连接 → 封装基板布线 → 外部焊点 → PCB。

局部桥结构的某些网络可直接进入封装基板，不必经过桥。电源、地与不同信号的路径可以不同，不能由一个剖面连线推导全部网络。

混合键合通过金属与介质表面的直接结合实现连接，与有焊料微凸点的结构不同；不能给混合键合界面自动添加焊球形状和焊料间隙。
