# RDL布线、介质与层间过孔

## RDL由什么组成

重布线层（redistribution layer，RDL）将连接点重新分配到所需位置。完整RDL结构包含导体与绝缘介质，通常还包含焊盘、层间过孔及表面保护结构；它不是整面连续铜板。

| 结构 | 几何位置 | 功能 |
| --- | --- | --- |
| 金属走线 | 某个布线层内 | 在平面内连接不同位置 |
| 焊盘 | 凸点或过孔的连接处 | 提供连接和过渡区域 |
| 介质 | 金属之间及上下层之间 | 电绝缘并构成布线结构的支撑环境 |
| 层间过孔 | 穿过指定介质层 | 连接不同高度的金属层 |
| 保护层及开口 | 外露连接表面附近 | 覆盖需保护区域，露出连接位置 |

## 横向布线与垂直引出

RDL主要通过走线完成横向连接，通过介质内过孔换层。硅中介层中的TSV穿过硅体，与仅穿过RDL介质的过孔不是同一实体。RDL走线可以接到TSV端部焊盘，但不能将整条路径都称为TSV。

RDL可制作在硅、玻璃或模塑结构等载体上；RDL中介层则指以RDL互连叠层承担中介作用的结构。存在RDL不意味着载体一定是硅。

## 如何区分尺寸

线宽是导体自身横向宽度，线距是相邻导体边缘之间距离，节距是重复结构的中心距离。金属厚度与其上方介质厚度属于不同实体；介质总厚度也不一定等于两金属表面之间的净间隙。

布线层数说明金属层的数量，不能直接当作“导体加介质”的实体总数。铜覆盖率表示指定区域和指定层中的铜面积比例，同一层内可能存在明显局部差异。
