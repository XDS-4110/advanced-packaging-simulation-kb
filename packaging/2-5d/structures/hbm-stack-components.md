# HBM存储堆栈与逻辑芯片的结构关系

## HBM本身是多层组件

HBM通过垂直堆叠多个DRAM裸片形成存储组件。采用基底芯片的结构中，基底芯片位于DRAM堆栈下方，承担与堆栈及外部接口相关的功能；具体功能和是否设置该芯片取决于器件架构。

| 部件 | 位置 | 结构含义 |
| --- | --- | --- |
| DRAM裸片 | 堆栈的存储层 | 每层具有自身硅体和电路 |
| 基底芯片（base die） | 若采用，则位于DRAM层下方 | 构成底部接口或逻辑层，不等同于封装基板 |
| 芯片内TSV | 穿过相应硅片 | 将连接引至另一侧 |
| 层间连接 | 相邻芯片之间 | 可采用微凸点，具体架构也可能采用混合键合 |
| 堆栈外部端子 | 堆栈底面 | 将HBM接到中介层或桥接互连 |

## 两套TSV、两类连接

HBM TSV与硅中介层TSV位于不同硅体内，不是一根贯穿整个封装的长铜柱。HBM内部芯片间连接和HBM底面到中介层的连接也应分开理解。

## 在2.5D封装中的位置

HBM堆栈通常与逻辑芯片并排安装，通过下方高密度布线交换信号。HBM本身的垂直堆叠不意味着它放在逻辑芯片顶部；若存储直接堆在逻辑上方，则应另外描述该垂直集成关系。

HBM堆栈顶面与逻辑芯片背面高度可能不同。层数标签不能独立确定总高度，总高度还与裸片厚度、基底芯片、层间连接和外部连接的定义有关。
