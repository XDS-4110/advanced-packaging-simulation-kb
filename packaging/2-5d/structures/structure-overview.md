# 2.5D结构总览与层级关系

## 2.5D描述的是芯片之间怎样集成

2.5D封装通常把多个功能芯片并排放置，通过中介层或局部高密度互连结构建立芯片间连接。芯片可以是计算芯片、I/O芯片或存储堆栈。并排集成不要求它们的厚度、顶部高度或内部结构相同。

BGA描述封装的外部端子，2.5D描述内部集成架构。因此一个器件可以同时是2.5D封装和BGA封装。多芯片直接安装在普通基板上，也不能仅凭“有多个芯片”就确定它属于哪一种2.5D架构。

## 典型硅中介层结构，从上到下

```text
  逻辑芯片                 HBM存储堆栈
  芯片下微凸点             堆栈底部互连
  ─────── 中介层表面细布线 ───────
             硅中介层及TSV
          中介层到基板的连接凸点
             多层封装基板
                BGA焊球
                 PCB
```

示意表示层级和连接关系，不表示尺寸比例；各处底填、盖体等未在图中展开。

| 部件 | 位置 | 作用 |
| --- | --- | --- |
| 功能芯片 | 中介层或桥接结构上方 | 承担计算、存储、接口等电路功能 |
| 中介层 | 功能芯片与封装基板之间 | 提供芯片间细布线和向下引出连接 |
| 封装基板 | 中介层下方 | 承载组件，将连接重新分布至外部端子 |
| 外部焊球 | 基板底面 | 连接到系统PCB |
| PCB | 封装之外 | 系统级供电、信号连接和机械承载 |

## 三种结构尺度

芯片内部的器件与金属布线、封装内部的芯片间互连、封装到PCB的板级互连属于不同尺度。芯片间信号可以沿中介层横向传输；对外信号和供电则按网络设计通过垂直连接进入封装基板。不能把所有连接画成一根从芯片直通PCB的导体。

HBM内部可以是3D堆叠，同时HBM与旁边逻辑芯片之间采用2.5D集成；这两个描述不矛盾。
