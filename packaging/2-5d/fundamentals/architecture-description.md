# 2.5D架构不能只靠名称描述

## 回答的问题与结论

综述把EMIB桥接列为2.5D实现。建立案例时应记录实际互连结构，而不是假设所有2.5D封装都有同样的全尺寸中介层。

## 适用对象、假设与限制

只提供架构识别框架，不提供厂商当前工艺规格；与已有chiplet装配描述互补。

## 原理、公式与单位

本条为定性知识与资料整理要求，不提供可直接导入的参数、拟合公式或寿命常数。尺寸、时间、温度及物性数据必须与单位和来源一起登记。

## 资料整理步骤（本项目建议）

注明芯片布局、桥接或中介层范围、基板、每一级连接和垂直通孔是否实际存在。

## 验证方法与常见错误

检查剖面与部件清单；示意图不提供的尺寸保留缺失，不从图片比例估算为确定值。
